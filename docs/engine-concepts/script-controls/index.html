Script controls

A fundamental aspect of Brakeza3D is the script execution controls. You can access them from the main menu under the Script Controls section. You will also find these options in the toolbar.

ActionDescription
Play scriptsSwitches to execution mode. In this state, all scripts linked to the project/objects run their code every frame.
Stop scriptsStops the execution of the scripts.
Reload scriptsReloads all scripts linked to the project/objects.
